Mohamed Hussein Ramadan - Portfolio Website

Files included:
- index.html: Main portfolio page
- styles.css: All styling and responsive design
- script.js: Menu and scroll animations

How to use:
1. Extract the ZIP file.
2. Open index.html in any browser.
3. To edit text, open index.html with VS Code or any text editor.
4. To change colors, edit the CSS variables at the top of styles.css.

Designed for a Machine Learning / Data Analytics portfolio.
